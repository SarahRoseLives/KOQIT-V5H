# Research sources

These third-party projects were used during the V5H research. They are **not
vendored in this repository**; fetch them from upstream and respect their
licenses.

| Project | URL | Relevance |
| --- | --- | --- |
| gxipl | <https://github.com/linux-goxceed/gxipl> | Open CK610 IPL, `GXBC` boot protocol, TABLE/CRC notes |
| gxdl-c | <https://github.com/linux-goxceed/gxdl-c> | C UART BootROM flasher |
| gxdl-rs | <https://github.com/linux-goxceed/gxdl-rs> | Rust UART BootROM flasher |
| libre-gxdl | <https://github.com/matu6968/libre-gxdl> | Python flasher, Taurus/Taurus-6605H1 loaders |
| McMCCRU GX6605S builder | <https://github.com/McMCCRU/gx6605s_linux_fw_build> | Working GX6605S Linux SAT>IP image builder |
| gx6605s-emu | <https://github.com/RalphTamer/gx6605s-emu> | C-SKY ABI v1 emulator, OSD/CIR/SPI models, disassembler |
| C-Sky Linux 4.9.y | <https://github.com/c-sky/linux-4.9.y> | GX6605S DTS and `gx66xx_defconfig` |
| C-Sky tools | <https://github.com/c-sky/tools/tree/master/gx6605s> | CK610 spec, boot.elf, PCB, generic loader |
| C-Sky addons | <https://github.com/c-sky/addons-linux> | Vendor framebuffer/VPU driver examples |
| xboot GX6605S | <https://github.com/GX-OSS/xboot-gx6605s> | MIT GX6605S register definitions |
| T-Head QEMU | <https://github.com/T-head-Semi/qemu> | C-SKY ABI v1 translator reference |
| GX6605s-receiver-for-Himawarri | <https://github.com/vk-hca/GX6605s-receiver-for-Himawarri> | GX6605S TCP DVB-S2 notes |
| 3ABN V5H update PDF | <https://3abn.org/pdfs/news/Koqit-V5H-H265.pdf> | Public V5H update instructions |

The snapshots used locally were fetched on 2026-11-19. Upstream may have
changed since; use the links above for the current source.
